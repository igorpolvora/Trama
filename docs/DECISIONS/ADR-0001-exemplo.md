# ADR-0001 — Exemplo de registro técnico

## Status

Proposto

## Contexto

Este arquivo serve como exemplo da convenção de documentação de decisão técnica para o projeto Trama.

## Decisão

A arquitetura do MVP será orientada por Django + PostgreSQL + HTMX, com foco em visibilidade centralizada e autenticação reforçada.

## Consequências

- Permite implementação consistente em incrementos.
- Requer revisão humana para custos e segurança.
- Ainda depende de decisões de produto e de revisão técnica.
